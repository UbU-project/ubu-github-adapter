# Contract

## Import Contract

The adapter imports GitHub repository data from fixture JSON or live GitHub API
responses and normalizes the data into source structs under `src/sources`.
Source IDs and source URLs are preserved.

## Candidate Contract

Imported GitHub issues, pull requests, and CI events are mapped to UbU candidate
objects. Candidate tasks use canonical UbU task IDs generated by
`ubu_core::UbuId` with the `task_` prefix and UUIDv7 suffix.

GitHub-derived imports use `AuthoritySource::Delegated`. Approved projection
writes record the approval authority source from the approval object.

## Projection Contract

Projection previews are immutable batches. A live GitHub write is allowed only
when a `ProjectionApproval` approves the exact preview ID.

Phase 1 writes are restricted to:

- Applying or removing UbU-managed labels.
- Creating UbU-managed comments.
- Creating UbU-managed issues.
- Creating missing managed labels `ubu` and `ubu-managed` through managed-label
  preflight operations.

No arbitrary label creation, issue close/reopen, issue body rewrite, comment
deletion, or direct canonical store mutation is allowed in Phase 1.
